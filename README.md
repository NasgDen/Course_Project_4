# Проект "Сервис рассылок сообщений"

## Описание
Сервис рассылок сообщений написан на языке программирования Python с помощью фреймворка Django.
Фреймворк Django - это набор инструментов, библиотек и правил, которые помогают разработчикам создавать приложения, упрощая и ускоряя процесс разработки. Фреймворк предоставляет структуру, внутри которой можно разрабатывать веб-приложения.
Django использует шаблон проектирования MTV (Model — Template — View).
Сервис позволяет пользователям управлять рассылками сообщений для клиентов, в том числе создовать, редактировать, просматривать и удалять получателей рассылок, письма, а также формировать рассылки для нескольких получателей.
Реализована автоматическая отправка рассылок по расписанию через кастомную команду runapscheduler.

## Описание Моделей
Приложение message - модуль моделей models.py:
1. MailingRecipient - Описание полей модель - Получатель рассылки.
2. Message - Описание полей модель - Сообщение.
3. Distribution - Описание полей модель - Рассылка.
4. AttemptedMailing - Описание полей модель - Попытка рассылка.

Приложение users - модуль моделей models.py:
1. CustomUser - Описание полей модель - Пользователи.

## Установка

1. Клонируйте репозиторий:
```
git clone https://github.com/NasgDen/Course_project_4
```
2. В PyCharm установите менеджер проекта poetry.
3. В PyCharm устанавливаем все зависимости проекта из файла pyproject.toml
4. Переименуйте файл .env.sample в .env. Заполните файл конфигурации .env параметрами для подключения к базе данных.

## Использование:

1. В терминале введите: python3 manage.py runserver
2. Сервер запускается по адресу: 127.0.0.1:8000
3. В браузере введите адрес: http://127.0.0.1:8000/
